# Vocabulary Flashcards

This repository contains a simple HTML-based flashcard trainer for learning vocabulary.

Open `flashcard.html` in your browser to start practicing. The page loads a large vocabulary list from `data.js` covering all 30 "Let's Voca" days as well as extra units. Choose a unit from the drop-down, type the word's spelling, and use the hint or show-answer buttons when needed. Points and streak bonuses are awarded for correct answers.
