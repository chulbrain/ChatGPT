# Vocabulary Flashcards

This repository contains an HTML-based flashcard trainer for learning vocabulary.

Open `flashcard.html` in your browser to practice. The page loads a large word list from `data.js` covering all 30 "Let's Voca" days and extra units. Choose a unit and the number of questions to begin.

During the quiz you can request a hint or show the answer, earn points with streak bonuses, and see your progress with a timer and progress bar. Incorrect words appear in a review list so you can study them again until you get everything right.
