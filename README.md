# Vocabulary Flashcards

This repository contains an HTML-based flashcard trainer for learning vocabulary.

Open `flashcard.html` in your browser to practice. The page loads a large word list from `data.js` covering all 30 "Let's Voca" days and extra units. Choose a unit and the number of questions to begin.

During the quiz you can request a hint or reveal the answer. Points and streak bonuses give a little reward when you keep answering correctly. Wrong answers don't reveal the correct spelling; you can try again or ask for the answer. At the end you'll get a review list of all missed words so you can repeat them until you know them all.
